# Keyboard Shortcuts

All shortcuts can be changed in **Settings → Shortcuts**. The defaults are
listed below.

---

## Palette

Active while the GlowSnap palette has focus.

| Action | Default |
| ------ | ------- |
| Take full screen screenshot | `Alt+1` |
| Take area screenshot | `Alt+2` |
| Start a recording | `Alt+3` |
| Open Studio | `Alt+4` |

---

## Application

| Action | Default |
| ------ | ------- |
| Return to the palette | `Ctrl+Alt+S` |

---

## Tools (editor)

| Action | Default |
| ------ | ------- |
| Select tool | `V` |
| Crop tool | `C` |
| Arrow tool | `A` |
| Text tool | `T` |
| Pen tool | `P` |
| Rectangle tool | `R` |
| Circle tool | `O` |
| Eraser tool | `E` |

---

## Editor

| Action | Default |
| ------ | ------- |
| Edit the selected text | `Enter` |
| Delete the selected shape | `Delete` / `Backspace` |
| Undo | `Ctrl+Z` |
| Redo | `Ctrl+Shift+Z` or `Ctrl+Y` |
| Export image | `Ctrl+S` |
| Copy shape | `Ctrl+C` |
| Paste shape | `Ctrl+V` |
| Duplicate shape | `Ctrl+D` |
| Deselect all | `Escape` |
| Zoom in | `Ctrl+=`, `Ctrl++` or `Ctrl` + numpad `+` |
| Zoom out | `Ctrl+-` or `Ctrl` + numpad `-` |

---

## Area selection overlay

Active while you are choosing a region to capture.

| Action | Default |
| ------ | ------- |
| Confirm the selection | `Enter` |
| Cancel the selection | `Escape` |

---

## Rebinding a shortcut

1. Open **Settings** (the ⚙ button in the palette).
2. Scroll to **Shortcuts**.
3. Click the shortcut you want to change.
4. Press the new combination — for example `Ctrl+Alt+S`.
5. The binding is saved immediately and takes effect right away.

Press `Escape` while capturing a binding to cancel. Click the **✕** that
appears next to a customised shortcut to restore its default.

> Shortcuts are ignored while you are typing in a text field.
