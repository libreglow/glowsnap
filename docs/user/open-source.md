# Open Source & License

GlowSnap is developed in the open. Everyone is welcome to contribute.

---

## Open Source

You can help by:

- Reporting bugs
- Suggesting features
- Improving documentation
- Translating the application
- Designing icons
- Writing code
- Testing new releases

The full contribution guide lives in
[`CONTRIBUTING.md`](../../CONTRIBUTING.md) at the root of the repository, and the
[developer documentation](../developer/README.md) explains how the project is
put together.

---

## Privacy

GlowSnap does not rely on cloud services.

- No account
- No tracking
- No analytics
- No uploads

Your screenshots and recordings stay on your computer, in the folders you chose.
