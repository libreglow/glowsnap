# Roadmap

GlowSnap is developed in the open. This page describes where the project is
heading.

---

## Version 1.0.0

### Capture

- Full screen screenshots
- Area selection
- Screenshot gallery

### Editor

- Basic annotation tools
- Crop
- Drawing

### Distribution

- Stable Linux release
- Flatpak package
- MIT License release

---

## Future Plans

GlowSnap will continue evolving after the first stable release. Potential
improvements include:

- Advanced visual effects
- Blur tool
- Pixelation tool
- Better annotation system
- Window capture
- GIF export
- Screen recording improvements
- Keyboard shortcut customization
- Better multi-monitor support
- Plugin architecture
- Performance improvements

---

## How the roadmap works

The roadmap is a direction, not a contract. Feature requests and bug reports
from the community decide the actual order of work. If something you need is
missing, [open an issue](https://github.com/libreglow/glowsnap/issues) — votes
and comments help decide what gets built next.
